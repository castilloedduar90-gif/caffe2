# Café Aroma — Landing page

Landing page responsive para una cafetería en Huaura–Huacho, construida con HTML semántico, CSS y JavaScript vanilla.

## Archivos

- `index.html`: estructura, contenido, menú, galería, formulario y mapa.
- `css/styles.css`: identidad visual y estilos responsive.
- `js/main.js`: navegación móvil, fecha mínima y envío de reservas a WhatsApp.

## Ejecutar localmente

1. Descomprime el proyecto.
2. Abre la carpeta `cafe-aroma` en Visual Studio Code.
3. Abre `index.html` en tu navegador o utiliza la extensión Live Server.

No requiere instalación de paquetes ni compilación.

## Personalización necesaria antes de publicar

- Confirma la dirección exacta para ajustar el mapa.
- Reemplaza precios y productos de ejemplo por tu carta real.
- Cambia las fotografías por imágenes propias cuando estén disponibles.
- Confirma que el número de WhatsApp `+51 937 011 574` sea el correcto.
- Añade horarios de atención y políticas de reserva.

## Funcionamiento de reservas

El formulario valida los campos en el navegador y abre WhatsApp con el mensaje preparado. No almacena reservas ni confirma disponibilidad automáticamente; el equipo debe responder al cliente.

## Dependencias externas

- Google Fonts para tipografías.
- Imágenes alojadas en Unsplash.
- Google Maps Embed para el mapa.
- WhatsApp para el contacto y las solicitudes de reserva.

Se necesita conexión a internet para cargar estos recursos externos.

## Logo de Café Aroma
El logo proporcionado está guardado en `assets/logo-cafe-aroma.jpg` y se muestra en la cabecera y el pie de página. Para cambiarlo, reemplaza esa imagen conservando el mismo nombre de archivo.
